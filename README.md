# CLI StopWatch ⏱️

A lightweight, fast, and reliable command-line stopwatch written in **Rust**. Built for efficiency and precise time tracking directly from your terminal.

## ✨ Features

- **High Precision:** Built using native Rust time libraries for accurate elapsed time tracking.
- **Interactive Controls:** Clean command-line interface to start, stop, lap, and reset your timer.
- **Zero Bloat:** Lightweight design with minimal dependencies.
